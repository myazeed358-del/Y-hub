# Learning kicker

**Source evidence:** `artifacts/y-hub/src/App.tsx`, `SectionKicker`.

## Visual contract

- Small bold uppercase or short-label text.
- Uses the primary teal token.
- Establishes hierarchy before a heading without competing with the heading.
- Works in Arabic RTL and English LTR contexts.

## Usage

Use for lesson categories, path labels, and section labels. Do not use it for
long descriptions or as the only way to communicate a status.
