# Learning sidebar

**Source evidence:** `artifacts/y-hub/src/App.tsx`, `Shell`.

## Visual contract

- Persistent deep navy surface.
- Teal active marker and active background treatment.
- Warm off-white text with lower-contrast supporting labels.
- Rounded navigation items with generous touch targets.
- Supports RTL placement on the right and LTR placement on the left.

## Usage

Use for course-level navigation and persistent learning context. Keep the
current location visible and do not reuse the sidebar accent as a competing
content card color.
