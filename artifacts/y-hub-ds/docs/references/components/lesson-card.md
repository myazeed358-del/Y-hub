# Lesson card

**Source evidence:** `artifacts/y-hub/src/App.tsx`, lesson rows in
`Home` and `CoursePlan`.

## Visual contract

- Card surface uses the warm card token on the paper canvas.
- Progress ring anchors the row.
- Title is bold and subtitle is muted.
- Lesson number and technical metadata use the mono face.
- Rounded corners and a quiet border keep the list scannable.

## Usage

Use for a lesson in a course list or dashboard. Keep one clear primary action
per row and avoid adding unrelated controls inside the card.
