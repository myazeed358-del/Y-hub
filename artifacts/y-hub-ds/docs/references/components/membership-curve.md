# Membership curve

**Source evidence:** `artifacts/y-hub/src/App.tsx`, `MiniCurve`.

## Visual contract

- Minimal line plot with quiet axes.
- Teal represents the default learning curve.
- Amber and coral distinguish alternate function types or attention states.
- The curve is the focus; grid decoration stays secondary.

## Usage

Use for fuzzy membership functions and mathematical previews. Keep the curve
inside a bounded container and label the variable or function type nearby.
