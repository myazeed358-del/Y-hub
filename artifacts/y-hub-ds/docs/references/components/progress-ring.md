# Progress ring

**Source evidence:** `artifacts/y-hub/src/App.tsx`, `ProgressRing`.

## Visual contract

- Circular track uses muted color.
- Progress uses primary teal.
- Numeric percentage is centered and uses the mono face.
- The component remains legible from 0 through 100 percent.

## Usage

Use beside lesson or course completion. Keep the value visible; the ring is a
reinforcement, not a replacement for the numeric readout.
