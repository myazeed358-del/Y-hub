## التنفيذ

دعم إضافي داخل AI Practice القائم، دون صفحة أو محرك أو اعتماد جديد. يقترح المولد مهمة تكامل موثقة بالمقاطع المختارة؛ يتحقق الخادم من خياراتها باستخدام **DerivativeEngine** الحالي. يشتق الخيارات الأربعة ويقارن جميع المعاملات الصحيحة، دون تقريب عددي أو قبول مفتاح أو شرح يرسله النموذج. يجب أن تكون إجابة واحدة فقط صحيحة. يولد الخادم السؤال والخيارات والخطوات بالعربية أو الإنجليزية وLaTeX، ويستمر إخفاء الحل والمراجع حتى تأكيد التدريب أو تسليم الاختبار الذاتي.

العقد الجديد `polynomial-antiderivative-v1`:

```json
{
  "method": "polynomial-antiderivative-v1",
  "task": {
    "kind": "polynomial_antiderivative",
    "variable": "x",
    "coefficients": [2, -6, 3],
    "options": [[0, 2, -3, 1], [0, 2, -6, 1], [0, 2, -3, 3], [0]]
  }
}
```

المعاملات مرتبة من الثابت إلى أعلى قوة؛ المتغير x أو t فقط. كثير الحدود داخل التكامل درجته0–7 ومعاملاته الصحيحة بين−100 و100. خيارات الدالة الأصلية درجتها0–8 ومعاملاتها الصحيحة بين−800 و800. يستوعب C كل ثابت إضافي قبل العرض والتخزين، وتُرفض خيارات تختلف فقط بثابت أو بأصفار نهائية. المثال ينتج:

\[
\int (3x^2-6x+2)\,dx=x^3-3x^2+2x+C
\]

لا تصحيح حر عام، ولا معاملات كسرية أو تكاملات محددة أو دوال عامة. إذا لم يدعم السؤال هذا العقد فلا يحصل على وسم تحقق أو نتيجة محسومة تلقائيًا. لم تتغير خوارزميات `services/math`؛ أعيد استخدام محولات كثيرات الحدود الصغيرة، وبُني artifact الخادم من المصدر نفسه وفُحص تطابقه. شرح قاعدة التكامل يتبعه تحقق اشتقاق كل حد ثم المجموع؛ لا يُنسب حساب إلى نموذج اللغة.

ملاءمة السؤال التربوية للمقاطع تبقى بحاجة لاختبار جودة المزود؛ المحرك يتحقق من المعادلة، بينما الخادم يتحقق من هوية المراجع وصلاحياتها.

## قاعدة البيانات والأمان

الترحيل الجديد الوحيد **0056_practice_antiderivatives.sql**، بعد0055 دون تغيير SQL التاريخي:

- قاعدة البيانات تتحقق من البنية والحدود والهوية، ولا تدعي تنفيذ محرك رياضي ثانٍ داخل SQL. حساب الإجابة وظيفة العامل الموثوق. صاحب قاعدة البيانات وصلاحيات الخدمة ليسا حدًا مقاومًا للتلاعب المطلق.
- قفل المستخدم/الشعبة يمنع قبول سؤالين متكافئين بالتزامن. النص العربي/الإنجليزي والمتغير وترتيب الخيارات ليست وسيلة لتجاوز المنع. الحد الثابت داخل التكامل يظل فرقًا رياضيًا حقيقيًا.
- التكرار المقصود يسمح بتاريخ الجلسات السابقة فقط، ولا يسمح بتكرار السؤال داخل الجلسة نفسها. إعادة محاولة نشر الموضع ذاته لا تكتب مفتاحًا جديدًا أو تضاعف النتيجة.
