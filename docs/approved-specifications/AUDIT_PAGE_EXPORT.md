# Decision69: audited export of the current page

Owner review now includes **Export current page (JSON)**. The client sends only the current event IDs (1–25); the database fetches the authoritative, already-redacted events and identity snapshots. It rejects null, empty, duplicate, oversized or missing selections. Ordering matches the audit page. Internal search vectors and transaction IDs are excluded. The response has a format version, issuance time, export ID and explicit `selected_page` scope; it never claims to contain all matching events.

`export_audit_page` checks the Owner's **current database role** under the existing profile lock. It cannot be called by anonymous or service roles; authenticated non-Owners are denied before reading any selected record. This security-definer RPC uses an empty search path and explicit grants because issuing an export must append trusted evidence that clients cannot insert themselves. No caller actor/role or cached JSON is trusted. No underlying file contents are read.

The export ID is the immutable evidence event's ID. Evidence contains the actor snapshot, selected event IDs/count, JSON format and `delivery: issued`. It is reserved for Owner visibility and contains no copied file content. The database returns data only after creating evidence in the same transaction; any evidence failure rolls back the operation. Repeated requests are separately recorded issuances. **Issuance is not proof of download or disk storage**; a lost response may still leave committed evidence.

The browser validates response shape and exact selection membership, requests a JSON download, removes the temporary link and revokes its object URL. It avoids spreadsheet formula interpretation by using JSON. Empty/loading/error pages disable export. Double clicks share one pending operation; identity/page changes or refresh cancel the request and suppress late downloads. Errors do not expose database messages and warn that issuance may already have been recorded. Arabic/English status text distinguishes download requests from completed storage.
