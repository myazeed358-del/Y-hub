# بناء حدّ كثير حدود بصريًا

متابعة28/29 من الرأس المنشور `57202be` ضمنPR48. أضيف محرر محدود لحدّ واحد إلى حقل الإجابة المكتوبة؛ ليس محررًا رياضيًا عامًا، ولا يوسع عقد التصحيح أو يدعي صحة الإجابة.

commit التنفيذ: `e86ddca`.

## التنفيذ

`PolynomialTermBuilder.tsx` يعرض جزءًا قابلًا للفتح داخل حقل الإجابة، يتيح معاملًا صحيحًا بين−800 و800، ومتغيرx أوt، وأسًّا بين0 و8. المعاينة تعرض الضرب والأسّ المرتفع بعناصرReact نصية؛ لا HTML مدخل أوeval أو قراءة لمفتاح الإجابة.

يدعم المعامل أرقامًا عربية وفارسية وإشارة الطرحUnicode. يرفض الكسر والصيغة العلمية والفراغ والخارج عن الحدود دون تقريب أو إدراج. الدرجة0 تنتج ثابتًا، والمعامل0 ينتج0، وبقية الحدود تنتج صيغة مثل`-3*t^8` يقبلها المحلّل القائم. صلاحية حد منفرد لا تضمن صحة الإجابة أو صلاحية مجموع المعاملات بعد دمجه؛ التحقق الخادمي يبقى المرجع.

زر الإدراج يعيد استخدام مسار اللوحة القائم: يستبدل التحديد أو يدرج عند المؤشر، ولا يمحو بقية النص، ويحافظ على حد400حرف وتعطيلfieldset. لا يضيف علامة جمع تلقائيًا بين الحدود؛ الواجهة تشرح استخدام+ أو− واختيار متغير السؤال. لا حفظ تلقائي لإعدادات المحرر محليًا أو تغيير لتخزين الإجابات.
