-0040 يملأ أجل الجلسات القديمة من نهاية المحاضرة، ويحتفظ بحالات excused القديمة وبسجل التدقيق. لا يعيد تكوين عضوية قديمة غير معروفة، ولا يغير أرقام أو معرفات المساقات والطلاب.
- انتهاء الحضور منطقي بوقت قاعدة البيانات؛ `get_attendance_session` و`attendance_report` وQR/check-in تعتمد الأجل. `state` الخام وحده ليس عقد القراءة الجديد. لا cron مطلوب، ولا ادعاء بحدث منفصل صدر لحظة الانتهاء دون معاملة.
- قبل النشر المعتمد: تقدير قفل/حجم جداول الجلسات، مراجعة نتائج التاريخ القديم، نشر SQL قبل واجهة RPC الجديدة، ثم اختبارات Staging بأدوار حقيقية معزولة. كلها PENDING؛ لا كتابة إنتاج.
-69 يغير نطاق قراءة Audit Log عن السياسة القديمة؛ لا يمكن اعتباره مجرد إظهار تبويب. المشاركة/الاستعادة تتطلب ACL خادميًا لا واجهة فقط.
- Vercel/Python bundle size: Known Deferred Issue؛ لم يُعد تشخيصه أو تعديله.
