## القرارات والسلوك المنفذ

**20 مكتمل محليًا في حدود النص المفهرس المدعوم؛22 محفوظ وموسع.** يستطيع الدكتور المخول تعريف فصول وموضوعات لكل PDF، وربطها بصفحات فعلية موجودة في فهرس ذلك الملف. يستطيع الطالب اختيار كتاب كامل أو صفحات يدوية أو فصل/فصول وموضوع/موضوعات، مع بقية المصادر ووحدات السيلابس القائمة. يضم اختيار عدة بنود اتحاد صفحاتها دون تكرار. تحرير الصفحات يدويًا يزيل اختيار الفصول صراحة؛ اختيار جميع الصفحات يعيد نطاق الكتاب.

المتصفح يرسل معرفات المصدر وإصداره ومعرفات البنود وإصدار الربط. يعيد الخادم بناء الصفحات ويمنع توسيع النطاق بصفحات أو أسماء مزورة. التوليد القائم يستخدم هذه الصفحات عبر مسار الاسترجاع نفسه. لا مسار توليد موازٍ ولا تعديل لمحركات الحساب أو حصص المزود.

عند نشر السؤال تُضاف أسماء الفصل/الموضوع من الربط الذي حفظه الدكتور إلى المراجع الخاصة، داخل المعاملة ذاتها. المرجع الخاص بموضوع يتضمن الفصل الأب عندما ينطبق على الصفحة. لا تُقبل أسماء يقدمها النموذج أو المتصفح. لا يظهر المرجع قبل تأكيد جواب التدريب أو تسليم الاختبار الذاتي. الاختيارات القديمة بالصفحات تبقى دون أسماء مفترضة. يعرض المكون القائم أسماء عربية/إنجليزية كنص آمن، مع رقم الصفحة والاقتباس، وتبقى آلية فتح الملف المخولة كما هي.

## قاعدة البيانات والصلاحيات

الترحيل الجديد الوحيد: `artifacts/y-hub/supabase/migrations/0054_ai_practice_outline_scope.sql`. لم تُعدّل ترحيلات تاريخية.

- `ai_practice_outlines`: سجل لكل مصدر PDF، مرتبط بالشعبة وجيل المصدر وإصدار الربط. RLS مفعل وإجباري، ولا SELECT/INSERT/UPDATE/DELETE مباشر لأي دور تطبيق أو service_role. القراءة والكتابة عبر RPC مخول فقط.
- `get_ai_practice_outline`: يعيد الربط الحالي بعد التحقق من الوصول الفعلي للشعبة. لا تكشف الإدارة العامة محتوى شعب غير مخولة. عند تغير الملف أو اختفاء صفحات الربط من الفهرس تُعاد حالة stale وبنود فارغة.
- `set_ai_practice_outline`: صلاحية الدكتور المعين الحالية، وأقفال التفويض القائم، وتحقق صفحات الفهرس، وإصدار متوقع للحفظ. تحديثان مختلفان لا ينجحان بالإصدار نفسه. إعادة الطلب نفسه بعد فقدان التأكيد لا تنشئ إصدارًا أو حدث تدقيق آخر.
- `resolve_ai_practice_selection`: يُستخدم أيضًا داخل المعاينة وإنشاء الجلسات، لذلك لا يمكن تجاوز التحقق باستدعاء RPC مباشرة. البنود محصورة بمصدرها وشعبتها وإصدارها؛ الموضوع لا يتبع إلا فصلًا وتكون صفحاته ضمن صفحات الأب.
- `current_scope`: يعيد فحص الجيل والربط وأقفاله قبل استخدام جلسة أو نشر سؤال. تغيير الربط يبطل الوصول إلى جلساته السابقة؛ لا يحذف أي إجابة أو سجل. نطاقات الصفحات اليدوية لا تتأثر بتغيير الأسماء. تعرض الواجهة هذا الأثر قبل الحفظ.
- `attach_outline_citations`: Trigger خاص يضيف أسماء موثوقة إلى مخزن أدلة الأسئلة، وليس جدولًا عامًا. يستفيد من الأقفال والتحقق في ناشري الأسئلة الحاليين.
- التدقيق إلزامي: فشل إدراج حدث التدقيق يُرجع تعديل الربط. يحجب محتوى البنود والأسماء في Audit Log ويحتفظ بهوية المنفذ والإصدار والكيان. أُضيف فلتر الكيان إلى واجهة التدقيق فقط.
- إبطال الربط يستبعد جلساته من تقرير الأداء ويزيد عدد الجلسات غير المتاحة. لا يختلق نتيجة جديدة ولا يعيد حساب بيانات تاريخية مخزنة. تجميع الأداء الدقيق حسب موضوع/فصل لا يزال عملًا لاحقًا ضمن42.
